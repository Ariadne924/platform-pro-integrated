# 因子格式说明（双文件协议）

本平台因子采用 **MD 文档 + Python 实现** 的双文件格式：MD 是唯一事实来源（元数据与公式以它为准），`.py` 是实现。两文件齐备且校验通过才会注册；孤立 `.py` 一律不注册。

- 内置因子：`factors/<ID>_<name>.md` + `factors/impl/<name>.py`
- 用户导入（热插拔）：`imports/factors/<ID>_<name>.md` + `imports/factors/impl/<name>.py`，也可在 Web 因子库页面上传
- 权威模板：`factors/TEMPLATE.md`；校验器实现：`src/superplatform/factors/protocol.py`

## 一、MD 文档结构

文件 = YAML frontmatter + 正文 10 个固定章节。

### 1. frontmatter 必填字段（规则 2）

```yaml
---
factor_id: MOM-001            # 见规则 3
name: demo_momentum           # 见规则 4
category: momentum            # 见规则 5
version: 1.0.0
status: active                # 见规则 6
frequency: 1h                 # 见规则 7
lookback_bars: 21             # 见规则 8（正整数，基于 1m 主K线）
inputs: [close]               # 见规则 9
params:                       # 自由键值对，原样透传给 compute(**params)
  window: 20
output:
  type: float
  description: "过去 window 根K线的简单收益率"
  direction: "值越大越看多"
implementation: factors/impl/demo_momentum.py   # 见规则 10
entry: compute                # 可选，默认 compute
created_at: 2026-08-13
---
```

可选字段（不校验但建议）：`updated_at`、`data_sources`、`tags`、`author`、`references`、`output.description/direction`（评级页展示用）。

### 2. 正文 10 章节（规则 11，须齐全且按序）

`## 1. 因子概述` / `## 2. 数学定义` / `## 3. 输入与参数` / `## 4. 计算步骤` / `## 5. 输出与解释` / `## 6. 数据依赖与频率` / `## 7. 边界条件与异常处理` / `## 8. 适用范围与已知局限` / `## 9. 有效性检验记录` / `## 10. 变更日志`

- 标题写作 `## 1. 因子概述（补充说明）` 也可（序号+标题前缀匹配，容忍后缀文字）。
- 「数学定义」章节**必须至少含一个 `$$...$$` LaTeX 公式块**（规则 12）。

## 二、实现文件（impl）

```python
def compute(data: dict[data_type, dict[symbol, DataFrame]], **params):
    ...
```

- **签名（冻结接口）**：`data` 是「数据类型 → {标的: DataFrame}」两层字典，K线 DataFrame 含 `timestamp/open/high/low/close/volume` 等列（UTC 时间戳）；`params` 来自 frontmatter 的 `params` 段。
- **返回**：含 `timestamp/value` 两列的 DataFrame（或 `FactorResult`，其 `values` 同形）。头部 lookback 内的 NaN 允许保留。
- **约束**：纯函数——禁止网络 IO、禁止随机性、禁止读写全局状态。
- 文件名必须为 `<name>.py`（与 frontmatter 的 `name` 一致），且路径必须位于 `factors/impl/` 或 `imports/factors/impl/` 下（规则 4/10）。
- `implementation` 相对路径先按仓库根解析；找不到时回退到 MD 所在插件根（所以 imports 下写 `factors/impl/x.py` 能命中 `imports/factors/impl/x.py`）。

最小示例（即内置 MOM-001）：

```python
import pandas as pd

def compute(data: dict, **params) -> pd.DataFrame:
    window = int(params.get("window", 20))
    kline = list(data["kline"].values())[0]
    result = pd.DataFrame({"timestamp": kline["timestamp"]})
    result["value"] = kline["close"] / kline["close"].shift(window) - 1
    return result
```

## 三、校验规则一览（失败返回「规则编号 | 字段 | 描述」）

| 规则 | 内容 |
| --- | --- |
| 1 | frontmatter 存在且 YAML 可解析（`---` 开头、`---` 行结束） |
| 2 | 12 个必填字段齐全 |
| 3 | `factor_id` 匹配 `^[A-Z][A-Z0-9]{1,7}-\d{3}$`（如 MOM-001、A101-023）且全库唯一 |
| 4 | `name` 为 snake_case；实现文件名必须为 `<name>.py` |
| 5 | `category` ∈ momentum / reversal / volatility / volume / technical / microstructure / basis_funding / onchain / sentiment / cross_asset / ml_feature / other |
| 6 | `status` ∈ draft / active / deprecated |
| 7 | `frequency` ∈ tick / 1m / 5m / 1h / 4h / 1d |
| 8 | `lookback_bars` 为正整数 |
| 9 | `inputs` 为非空列表，元素 ⊆ open / high / low / close / volume / quote_volume / trades / taker_buy_volume / vwap / funding_rate / open_interest / mark_price |
| 10 | `implementation` 指向 `factors/impl/` 内真实存在的 `.py`，可导入且含入口函数 |
| 11 | 正文 10 章节齐全且顺序正确 |
| 12 | 「数学定义」章节含 `$$...$$` 公式块 |

命令行验证：`superplatform factors list --status invalid` 可查看未过校验的因子及具体规则编号。

## 四、注册与热插拔

- 注册中心（`src/superplatform/factors/dual_registry.py`）同时扫内置 `factors/` 与 `imports/factors/`，用 **mtime 增量 diff**：只重扫变更文件，支撑数千因子。
- 落合规 MD+impl 到 `imports/factors/`，10 秒内自动注册（CLI 下次调用 / live 每 tick 即见）；**删 MD 即注销**；删 impl 只留 MD 不注册（list 中标 invalid + 规则 10）。
- 内置与 imports 同 ID 冲突时**内置优先**并告警（list 中标 conflict）。
- 校验通过的因子会包装成 exchangia `Factor` 实例注入 `FactorRegistry` 单例，供 evaluate/check/rating/bias-check/live/UI 全链路消费。
