# 算法问题与论文检索方向

本清单记录多币种、多频率、多源机器学习迭代中已经由代码或真实数据暴露的问题。它不是待办愿望表；每一项都包含当前证据、工程决策和适合检索论文的关键词。

## 1. 混合频率与发布时间对齐

**当前证据**：K 线已有 `1h/4h/1d`，资金费率原生为 `8h`，持仓量归档原生粒度更细且已聚合为 `1h`，基差当前只能可靠生成 `1d`。现有批量因子入口会把一次运行中的所有输入固定到同一频率，这不适合多源联合训练。

**风险**：简单前向填充可能把尚未公布的数据放到较早决策点；简单降采样会把“观测频率”和“可获得时间”混为一谈。

**工程方向**：每个因子保留原生频率与 `available_ts`，统一采用 publication-lag-aware backward as-of join；标签与成交价格只来自决策频率。不能原生服务某频率的因子不做伪造重采样。

**论文检索词**：mixed-frequency forecasting、MIDAS regression、multi-rate time series、ragged-edge data、publication lag、asynchronous features。

## 2. 高频高维训练成本

**当前证据**：一分钟数据一年单币约五十多万行；多币种、八个因子、多个 Walk-Forward 折和五种模型会产生大量重复拟合，历史实验曾耗时约十二小时。

**风险**：全量装入内存会超过本机约 16GB 内存；并行过度还会造成 DuckDB 争用和内存峰值。

**工程方向**：Gold 特征物化、按时间/币种分块、训练折缓存、训练期内相关性去冗余和稀疏筛选；先用快速档估算成本，再运行标准或完整实验。

**论文检索词**：online learning for time series、incremental gradient boosting、feature selection high-dimensional finance、successive halving、walk-forward optimization caching。

## 3. 非平稳与市场状态切换

**当前证据**：同一组因子在当前真实日频实验中样本外收益为负，且牛熊震荡分段表现差异明显。

**风险**：固定参数假设分布稳定；直接让行情分类器切换策略又容易过拟合。

**工程方向**：市场状态先只用于样本外分层评估；后续单独比较规则状态、HMM 和在线变点检测，状态切换策略必须使用独立外样本。

**论文检索词**：regime switching asset returns、hidden Markov model trading、Bayesian online change point detection、concept drift finance。

## 4. 尾部风险与强制清仓的顺周期性

**当前证据**：简单历史 VaR 对高频加密收益的波动聚集和厚尾反应不足。当前实现已把它降为对照，事前仓位默认使用 FHS 动态 VaR/ES、EVT/POT 尾部修正和 HAR-RV 波动率预测的保守组合；组合熔断另有预警、减仓、强制转现金、冷静期和分阶段恢复。

**风险**：波动上升时机械减仓可能卖在低点；冷静期和恢复速度设置不当会形成顺周期交易。

**工程方向**：先对 FHS/EVT/HAR-RV 做滚动越界率、条件覆盖和 ES 回测，不凭单次收益选择模型；熔断事件必须继续判定为风险失败。下一步比较 EVT 的估计方法、固定阈值与动态 CVaR、最大回撤控制和带交易成本的动态风险预算，并评估机械缩仓的顺周期代价。

**论文检索词**：filtered historical simulation、HAR realized volatility、peaks over threshold EVT high frequency、conditional coverage VaR backtest、Expected Shortfall backtesting、CVaR portfolio optimization、drawdown constrained portfolio、risk control procyclicality、volatility targeting crisis、optimal de-risking transaction costs。

**仍未解决的算法问题**：EVT 超阈值、风险回看窗和 EWMA 衰减目前是显式配置，不应在同一回测样本上反复调参；HAR-RV 当前按日聚合实现，尚未处理微观结构噪声和跳跃成分；多币种尾部相关仍未进入联合极端损失估计。这三项需要后续论文复现和独立外样本验证。

## 5. 多重检验与“挑最好模型”偏差

**当前证据**：模型、因子、频率、币种和参数组合增加后，即使全部使用 Walk-Forward，也可能靠大量尝试选出偶然赢家。

**工程方向**：记录完整实验族；在现有区块 Bootstrap 之外加入 Deflated Sharpe、PBO 或 Reality Check，并把被尝试但失败的实验保留下来。

**论文检索词**：deflated Sharpe ratio、probability of backtest overfitting、White reality check、multiple testing quantitative strategies。

## 6. 多币种协方差不稳定

**当前证据**：风险平价和 HRP 已可运行，但加密资产相关性会在极端行情中迅速趋同，普通样本协方差可能低估共同下跌风险。

**工程方向**：继续保留收缩协方差基线，比较 EWMA、DCC-GARCH、尾部相关和动态 HRP；压力测试中强制提高相关性，不能只使用历史均值。

**论文检索词**：dynamic conditional correlation crypto、covariance shrinkage portfolio、tail dependence copula crypto、hierarchical risk parity robustness。
