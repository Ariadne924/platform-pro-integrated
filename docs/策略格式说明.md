# 策略格式说明（双文件协议）

本平台策略采用 **MD 文档 + Python 实现** 的双文件格式，与因子协议同构：MD 是唯一事实来源，两文件齐备且校验通过才会注册；孤立 `.py` 一律不注册。

- 内置策略：`strategies/<ID>_<name>.md` + `strategies/impl/<name>.py`
- 用户导入（热插拔）：`imports/strategies/<ID>_<name>.md` + `imports/strategies/impl/<name>.py`
- 权威模板：`strategies/TEMPLATE.md`；校验器实现：`src/superplatform/strategy/protocol.py`

## 一、MD 文档结构

文件 = YAML frontmatter + 正文 7 个固定章节。

### 1. frontmatter 必填字段（规则 2）

```yaml
---
strategy_id: DEM-001          # 见规则 3
name: demo_threshold          # 见规则 4
version: 1.0.0
status: active                # 见规则 5
symbols: [BTCUSDT, ETHUSDT]   # 见规则 6
params:                       # 自由键值对，原样透传给 generate(**params)
  factor: MOM-001
  threshold: 0.0
max_leverage: 1               # 见规则 7（1~20）
implementation: strategies/impl/demo_threshold.py   # 见规则 8
entry: generate               # 可选，默认 generate
created_at: 2026-08-13
---
```

### 2. 正文 7 章节（规则 9，须齐全且按序）

`## 1. 策略概述` / `## 2. 逻辑与信号定义` / `## 3. 参数说明` / `## 4. 执行规则` / `## 5. 风控约束` / `## 6. 回测与有效性记录` / `## 7. 变更日志`

- 标题容忍序号+前缀匹配（同因子协议）。
- 「逻辑与信号定义」章节**必须至少含一个 `$$...$$` LaTeX 公式块**（规则 10）。

## 二、实现文件（impl）

```python
def generate(factor_results: dict[factor_name, dict[symbol, FactorResult]], **params):
    ...
```

- **签名（冻结接口）**：`factor_results` 是「因子名 → {标的: FactorResult}」两层字典，`FactorResult.values` 含 `timestamp/value` 两列；`params` 来自 frontmatter。
- **返回**：含 `timestamp/symbol/position` 三列的 DataFrame（或 `StrategySignal`，其 positions 同形）。`position` 是**目标仓位权重**（如 +1/-1/0），**策略不直接出订单**——订单转换由消费层负责（总敞口 100% 封顶、方向反转自动拆单、超资金拒单）。
- **约束**：纯函数——禁止网络 IO、禁止随机性、禁止读写全局状态。
- 文件名必须为 `<name>.py`，路径必须位于 `strategies/impl/` 或 `imports/strategies/impl/` 下（规则 4/8）；`implementation` 相对路径解析规则与因子一致。

最小示例（即内置 DEM-001）：

```python
import pandas as pd

def generate(factor_results: dict, **params) -> pd.DataFrame:
    factor_id = str(params.get("factor", "MOM-001"))
    threshold = float(params.get("threshold", 0.0))
    rows = []
    for symbol, result in (factor_results.get(factor_id) or {}).items():
        values = result.values
        v = values["value"].fillna(0.0)
        position = pd.Series(0.0, index=values.index)
        position[v > threshold] = 1.0
        position[v < -threshold] = -1.0
        rows.append(pd.DataFrame({
            "timestamp": values["timestamp"],
            "symbol": symbol,
            "position": position,
        }))
    if not rows:
        return pd.DataFrame(columns=["timestamp", "symbol", "position"])
    return pd.concat(rows, ignore_index=True)
```

## 三、校验规则一览（失败返回「规则编号 | 字段 | 描述」）

| 规则 | 内容 |
| --- | --- |
| 1 | frontmatter 存在且 YAML 可解析 |
| 2 | 9 个必填字段齐全 |
| 3 | `strategy_id` 匹配 `^[A-Z]{2,8}-\d{3}$` 且全库唯一 |
| 4 | `name` 为 snake_case；实现文件名必须为 `<name>.py` |
| 5 | `status` ∈ draft / active / deprecated |
| 6 | `symbols` 为非空字符串列表 |
| 7 | `max_leverage` 为 1~20 的数 |
| 8 | `implementation` 指向 `strategies/impl/` 内真实存在的 `.py`，可导入且含入口函数 |
| 9 | 正文 7 章节齐全且顺序正确 |
| 10 | 「逻辑与信号定义」章节含 `$$...$$` 公式块 |

## 四、注册与使用

- 注册/热插拔语义与因子一致：内置 `strategies/` 与 `imports/strategies/` 双目录扫描、mtime 增量 diff、删 MD 即注销、内置优先告警。
- 校验通过的策略包装成 exchangia `Strategy` 实例注入 `StrategyRegistry` 单例。
- 命令行：`superplatform backtest --strategy DEM-001`（回测 Sharpe/MaxDD）、`superplatform live --strategy DEM-001 --ticks 5`（模拟盘）；Web 四页可直接触发回测与模拟盘。
